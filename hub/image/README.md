# Hub Image

> Part of the Adro Platform monorepo. See the root [README](../../README.md).

## RaspAP

RaspAP is installed **natively** in the hub image — not managed from this repo.

- Configs live at `/etc/hostapd/`, `/etc/dnsmasq.d/`, `/etc/raspap/`
- Portal: `http://adro.local`
- Auto-starts on boot
- No repo config or container required
